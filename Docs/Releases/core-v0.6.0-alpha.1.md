# Wallflow Core 0.6.0 alpha 1

First developer alpha for Wallflow Core, the standalone native macOS wallpaper manager.

## Included

- Local folder-based wallpaper library with subfolder collections
- Search, color and appearance filters, favorites, and gallery previews
- Native macOS wallpaper application and image inspector
- No Ghostty, Matugen, Accessibility, FloatPane, or Homebrew dependency for everyday use

## Requirements

macOS 14 or later. Source builds require Apple Command Line Tools or Xcode.

## Distribution status

This is a private **draft release** for source review and release preparation. No signed or notarized application binary is included yet. The source archives provided by GitHub are not one-click macOS applications.

## Remaining before public distribution

- Confirm rights to redistribute bundled icon and screenshots
- Test first-run folder selection and filters on a clean Mac
- Package, Developer ID sign, notarize, and test a downloadable macOS app

See the `main` branch for source code and installation from source.
