# Asset and dependency audit

The MIT LICENSE in this kit is intended for code and documentation authored by Wallflow's owner. Only include other materials under this license if the owner has the rights to license them.

Before making the repository public or publishing binary downloads:

- Confirm that `Resources/AppIcon.icns` and `Docs/Brand/wallflow-icon.png` are original or licensed for public redistribution.
- Confirm that the README screenshots show only the Wallflow UI and image thumbnails that may be redistributed. Wallpaper previews can contain third-party artwork; avoid assuming that owning a wallpaper file grants redistribution rights.
- Keep the personal image library, generated palettes, and local user settings out of Git and release assets.
- Ghostty and Matugen are independently installed software. They are not redistributed or relicensed by Wallflow's MIT LICENSE.
- Review any future dependencies and record their licenses when vendoring or distributing them.

A private GitHub repository can be licensed under MIT while private. Publishing the repository requires that you are comfortable granting those permissions to others.
